# Water Connection Survey (Android)

A simple offline-first Android app for the chawl house survey.

## Included fields
- Resident / House Owner Name
- Contact Number
- Taxpayer? (Yes/No)
- House Type (Ground/G+1)
- Total Number of Rooms
- Number of Tax Slips (0/1/2)
- Optional remarks

No volunteer details are collected. Records are saved locally on the phone. Use **Export Survey to CSV** to save a spreadsheet-compatible file.

## Build APK
1. Install Android Studio on a computer.
2. Open this project folder (`WaterConnectionSurvey`).
3. Allow Gradle sync to finish.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location.

The project uses Android Gradle Plugin 8.7.3 and compile SDK 35.
